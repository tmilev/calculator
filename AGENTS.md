# Development Guidelines & Agent Instructions

Welcome to the **Calculator / Computer Algebra System** repository.

This project organizes guidelines, architecture notes, and development rules under the [`.agents/`](.agents/) directory. These documents are written to be equally clear and practical for both human developers and AI assistants.

## Structure & Categories

1. **General Instructions (Committed)**:
   - Shared guidelines, build instructions, architectural invariants, and code style conventions meant for any contributor or assistant working with this codebase.
   - Core development rules: [`.agents/rules/general.md`](.agents/rules/general.md)
   - Code style guidelines: [`.agents/rules/codestyle.md`](.agents/rules/codestyle.md)

2. **Personal / Local Instructions (Gitignored)**:
   - Developer-specific workflow preferences, local environment setups, port mappings, and transient task notes.
   - Located in: [`.agents/rules/personal/`](.agents/rules/personal/) (excluded from git via `.gitignore`)

Please refer to the files in [`.agents/rules/`](.agents/rules/) before writing or modifying code.
